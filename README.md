# AI QUEST v1.2.2

## 修正内容
- 前エリアを全クエストCLEARすると、必要Lv未満でも次エリアを解放。例：プロンプトの森を全CLEAR → Lv.4でも文章生成の街へ進行可能。
- CLEAR済みクエストは「もう一度」で何度でも再挑戦可能。
- 再チャレンジでは初回EXP・コインを二重取得しない。
- 旧v1.2 / v1.1のセーブデータを自動移行。
- index.htmlにCSSを内蔵し、CSS読み込み失敗でも表示が崩れにくいスタンドアロン構成。
- CSS/JSにv1.2.2のキャッシュバスターを付与。

## 起動
`index.html` をブラウザで開いてください。

## 推奨テスト
1. Q001をCLEAR → 「もう一度」が表示される。
2. Q001を再挑戦 → 再挑戦成功、報酬は二重加算されない。
3. プロンプトの森を全CLEAR、Lv.4の状態でマップへ戻る → 文章生成の街が「入る」になる。

※ style.css / script.js は分離版として同梱しています。index.htmlは単独でも表示できるようCSSを内蔵しています。
