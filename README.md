# AI QUEST v0.5 全面精査版

v0.4 / v0.4.1で発生した画面遷移・マップ描画の不具合を避けるため、
既知のプレイ可能版 v0.3 をベースに JavaScript を整理して再構築した安定版です。

## 対応範囲
- タイトル → 新規ゲーム → プロフィール → オープニング → マップ
- 続きから → セーブデータを読み込み → マップ
- LEVEL 1～2：Q001～Q006
- LEVEL 3：プロンプトの森 Q007～Q009
- EXPによるレベル判定
- Lv.3でプロンプトの森を解放
- Lv.5～9はマップ上でレベル到達時に「解放済み・準備中」と表示
- localStorageセーブ
- Q009の自由入力プロンプト簡易評価
- クリア後の正しいエリアへの復帰

## v0.5で重視したこと
- v0.4.xのような関数の後付け上書きを行わず、画面遷移を一本化
- 「冒険をはじめる」「続きから」のイベントを明示的に設定
- マップ描画をshowScreen内で確実に実行
- セーブデータが壊れていても初期状態へ安全に正規化
- 既存v0.3セーブデータとの互換を維持


## v0.5.1 重要修正
v0.5でHTML側に残っていた実際の `onclick` 名とJavaScript側の関数名が一致していない箇所を修正しました。

修正対象:
- 「冒険をはじめる」→ `startGame()`
- 「続きから」→ `loadGame()`
- 「この名前で冒険する」→ `createProfile()`
- オープニング「次へ」→ `nextOpening()`

また、続きからのセーブデータ読み込みを独立して処理し、存在しない場合は新規ゲームを勝手に作らないようにしました。
