# AI QUEST v1.1.2

## クエストクリア判定・保存処理の全面点検版

### 今回の修正
- すべてのクエストでクリア処理を `completeQuest()` に統一
- 正解時に `cleared` / EXP / コイン / スキルを同時に保存
- クエスト一覧を即時再描画して CLEAR を反映
- choice / multi / 自由入力の判定を個別に厳密化
- 複数選択は順番が違っても正解として判定
- 自由入力はキーワード＋文字数で評価
- 旧 v1.1 のセーブデータを v1.1.2 へ自動移行
- 重複・回答番号・キーワードなど、全18クエストの定義を起動時に自動監査
- 累積EXPを保持したままレベルを計算
