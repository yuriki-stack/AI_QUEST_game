# AI QUEST v1.1
## 安全・検証エリア追加版

生成AI初心者向け学習ゲーム「AI QUEST」の続編テスト版です。

### 今回の追加
- Q018「その情報、入力して大丈夫？」
  - 個人情報・機密情報などをAIへ入力する前の安全判断
  - 複数選択式
- Q019「安全な依頼に書き換えろ」
  - 個人を特定できる情報を避けた依頼への改善
  - 自由入力＋キーワード評価
- Q020「最後の依頼」
  - Q018/Q019をクリアすると挑戦可能
  - 作成→検証→改善→安全判断をまとめて確認
- AI仕事ギルドのQ017A「仕事プロンプト工房」も搭載
- localStorageセーブ
- PC/スマホ対応
- マップ・クエスト解放・EXP・コイン・スキル管理

### 起動
`index.html` をブラウザで開いてください。
サーバー不要の静的HTML版です。

### 注意
この版は学習用シミュレーションです。実際のAIサービスへ入力する機能はありません。
