# AI QUEST v0.6 完全再構築・動作確認版

既存v0.3～v0.5.1の画面遷移不整合を避けるため、ゲーム本体を1つのindex.htmlに再構築しました。外部script依存をなくし、主要ボタンはDOMContentLoaded前後に関係なく確実にバインドされます。

## 実装
- タイトル → 新規ゲーム → プロフィール → オープニング → マップ
- 続きから → セーブ読み込み → マップ
- Lv1～2 Q001～Q006
- Lv3 プロンプトの森 Q007～Q009
- EXP/コイン/レベル/セーブ
- Q009自由入力プロンプト評価
- Lv5～9エリアは解放表示のみ（クエストは後続版）

## 自動セルフテスト
`index.html?test=1` で、ブラウザ上で新規開始→Q009までの主要進行を自動実行します。画面右下に `SELF TEST: PASS` が表示されれば主要進行テスト成功です。
